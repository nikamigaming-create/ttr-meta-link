# TTR Meta Link 1.1.0 beta - TTR 1.1 compatibility

Direct Meta Link / Air Link helper with guarded API version/controller correction,
Meta FOV preservation, and scope colour-surface isolation. Targets the exact
TTR 1.1 and Meta IPC hashes in README.md. Unknown builds are refused.

Install the ZIP through MO2 below TTR. Connect Link and launch the normal game
entry. Keep only one LocalMetaLink.dll enabled. Seated controls and pool are
optional independent addons. No SteamVR or Virtual Desktop is required by this route.

Public source builds; exact mapped-image API/FOV/scope/shadow guard tests pass.
This 1.1 port has not received a fresh physical Meta headset acceptance run.
ScopeSurfaceGuard defaults on; optional NativeShadows defaults off and concerns
native actor shadows, not new environment shadows. No DLSS/AA/texture/Link presets,
original mod DLLs, Meta binaries or game content are distributed.
